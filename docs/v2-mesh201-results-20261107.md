# C1 201-segment validation mesh stress results

The frozen four-frame diagnostic completed using the predeclared action set and checks in [the design record](v2-mesh201-design-20261106.md). The reportable artifact is [c1_spatial_validation_mesh201_stress_v3.json](../outputs/audits/v2-20261106/c1_spatial_validation_mesh201_stress_v3.json), SHA-256 `feacdcd3b1ecbb4c52f4422aad165fa61737a9d963bd1f77814cc2d4b73d904c`. Earlier v1/v2 output files are preserved interim scorer artifacts; v3 includes the generation-manifest identity and per-frame generation diagnostics.

The scorer verified 480 exact C1 actions (12 methods × 10 seeds × four frames), unchanged action hashes, C1 input and physics-source hashes, frame identity and geometry, finite 70×70 matrices, generation passivity checks, and coarse-score reproduction within `1e-7 bit/s/Hz`. No pilot or test samples were selected, and no action was changed. All four 201-segment frames passed the generator's matrix and passivity checks. The 201-frame generation manifest is intentionally partial: it contains only indices 32, 96, 160, and 174, with 44 of the 48 expected validation frames absent and `ready_for_development_evaluation=false`.

With each frame's original 81-segment all-OFF RZF precoder fixed across meshes, the 480 action rows had these descriptive absolute rate shifts:

The largest residual 161→201 change was the previously identified pair action (seed 11, frame 174, 17 ON elements): its score shifted −3.1632 bit/s/Hz from 81 to 161, then +0.9031 from 161 to 201, leaving a −2.2600 difference between 81 and 201. This nonmonotone movement is a concrete reason not to treat 161 as converged or 201 as ground truth.

The selected set contains only **13 distinct action vectors** across 480 method/seed/frame records; 467 records are all-OFF. Frames 96 and 160 have only the all-OFF action across all 120 method/seed rows each. At frame 174, the maximum-shift action is informative as a stress case, but the sample has limited state diversity. Among selected paired method orderings, 11 of 140 non-tied comparisons reversed from 161 to 201; the small denominator reflects extensive action ties and is descriptive only.

This is a bounded diagnostic across four frames and three independent validation trajectories, with two selected frames from trajectory 10. It is neither a population bound nor a final mesh-convergence gate. The 201-segment ratio Δ/a = 2.388 is within the NEC-2 manual's stated extended-kernel approximation condition, but that local kernel statement does not bound coupled-channel or rate error. Further refinement and broader physical coverage remain open; no optimizer or performance conclusion follows from this subset.
