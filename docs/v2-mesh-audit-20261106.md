# C1 validation mesh-sensitivity audit

This is a fixed-action validation rescore for the v2 decision gate. It compares the locked 50 ms spatial actions selected under the frozen v1 protocol on 81-segment coarse impedance with the same actions scored on 161-segment validation impedance. It does not reoptimize actions, use pilot/test frames, or claim that the 161-segment model is converged.

The accepted artifact is [c1_spatial_validation_mesh161.attempt2.json](/home/parasite/Work/conference/atom-wise-ris/outputs/audits/v2-20261106/c1_spatial_validation_mesh161.attempt2.json), SHA-256 `a2dbf145a3f933312f8b3529ed473fb72d9510249ece683d3e074dfcbbc14e20`. Attempt 1 stopped before any action scoring because the adapter incorrectly expected 64 per-cell load entries; the gate actually records the two shared OFF/ON impedances. Attempt 2 uses the corrected adapter and passes the current gate contract. The main agent retains the first failed-attempt log separately.

The source actions are bound to the recovered validation JSONL hash `5aa864ddd148d5beb433bec1b685a8c26d67d700fea54b8313d499a9583edf7f`, with the matching selected 50 ms budget and current protocol hash `77f880fa16c489344b0009b21e1a5ad091fd4530b8c53cb74fc83053f0dc2d88`. Independent readback confirmed 5,760 unique method × seed × frame actions (12 × 10 × 48), byte-matched input hashes for the validation JSONL, metadata, selection, protocol, coarse data and scenario, physics gate, fine scenario, all 48 fine-frame NPZ files, and the three physical evaluator source files. Every rescore record's action hash matches the corresponding frozen bit vector, and every recomputed coarse score matches the frozen row exactly (maximum absolute difference 0.0). No held-out test file was read.

The primary comparison holds each frame's original all-OFF coarse RZF precoder fixed while changing only the impedance matrix. A separate sensitivity recomputes one common all-OFF RZF precoder from the fine mesh and uses it for every method on that frame. Across the primary fixed-precoder comparison, the maximum absolute action-rate shift was **3.1632 bit/s/Hz** (pair, seed 11, frame 174, trajectory 10, 17 ON elements); the 95th percentile absolute shift was **0.6696 bit/s/Hz**. **5,450 of 5,760 actions (94.6%)** shifted by more than 0.015 bit/s/Hz. The 0.015 value is the protocol's practical resolution criterion for its separate conditional held-out action audit; it is not a universal validation-mesh margin.

The mean method ordering is not invariant to this mesh change. Under the fixed coarse precoder, pair's mean rate moved from 15.5146 to 15.4490 bit/s/Hz; memory_ga moved from 15.0404 to 15.0695; mlp_ga moved from 15.0173 to 15.0372, while attention_ga moved from 15.0113 to 15.0632. MLP had the higher mean on the coarse mesh, but attention had the higher mean on the fine mesh (mean ranks 10→8 for MLP and 8→10 for attention; rank 12 is highest rate). Across matched seed/frame contexts, **1,976 of 13,968 non-tied pairwise method comparisons (14.15%)** reversed ordering. These are descriptive validation summaries over actions chosen under the 81-segment model, not new optimization results.

ON-count associations are retained per method and trajectory in the artifact. They vary by method and trajectory, so they do not identify a general causal rule for the direction of mesh shifts. The uncertainty summaries resample three validation trajectories; with only three independent clusters they are weak and descriptive. The fine-W sensitivity also differs from the fixed-W comparison because it changes both the impedance matrix and the precoder. It should not be substituted for the primary isolated-mesh contrast.

The C1 stop rule is triggered: **do not make optimizer-quality claims for searches run on the 81-segment model.** Use the 161-segment model as the v2 search/report reference while labeling it as an unverified mesh reference, not ground truth. This result is validation-only and does not satisfy the frozen v1 protocol's separate conditional test-action audit, which—if a coupled contrast is otherwise called improved—requires every primary-budget held-out returned action to be rescored under the predeclared 81→161 protocol and its declared 0.015 criterion. No 241-segment comparison was predeclared here, and more segments cannot be assumed more accurate without evidence.
