# Predeclared 201-segment mesh stress diagnostic

**Purpose:** Follow up the C1 validation result that the fixed-action 81→161-segment rate shift reached 3.1632 bit/s/Hz at validation frame 174. This bounded diagnostic asks how the same frozen actions respond from 161 to 201 segments. It does not establish a full mesh-convergence gate or a population bound.

## Frozen selection and scoring

The selected frames are fixed before reading any 201-segment results:

- 32, 96, and 160: the first validation frame from each of the three validation trajectories.
- 174: the frame with the largest absolute 81→161 shift in the accepted C1 audit.

For each of these frames, score the exact C1 50 ms spatial-validation actions: 12 methods × 10 seeds × 4 frames = 480 method/seed/frame actions. Do not search, update, or substitute any action. Keep each frame's original 81-segment all-OFF RZF precoder fixed across 81, 161, and 201 segments so the impedance mesh is the only changed quantity. The main contrast is paired 161→201 rate change; 81→161 and 81→201 are also reported for context. The index selection and C1 action hashes are verified by `scripts/audit_refinement_v2.py`.

## Checks declared before 201 outcomes

The run must verify that (1) the accepted C1 source and its hashes still match; (2) all 480 selected actions exactly match C1; (3) the four mesh cases have identical frame identities, wire centers, and lengths; (4) every impedance matrix is finite and 70×70; (5) the generation sidecar passes the generator's existing physical check (`minimum resistance eigenvalue ≥ −1e-6 Ω`, `maximum scattering singular value ≤ 1.0001`); and (6) recomputing each frozen action on the original 81-segment mesh reproduces its saved score within `1e-7 bit/s/Hz`, the existing C1 source-reproduction check. These checks validate inputs and scoring. **There is no pass threshold on 81→161 or 161→201 mesh deltas**, and no threshold will be selected from these outcomes.

The 24 mm wires have radius 0.05 mm. At 201 segments, Δ/a = 480/201 ≈ 2.388, above the NEC-2 manual's stated Δ/a > 2 condition for the extended thin-wire kernel's <1% kernel-approximation error, under the manual's assumptions. This does not bound full-network impedance, channel, or spectral-efficiency errors. The 241-segment ratio is about 1.992, below that stated condition, so it is excluded from this diagnostic. See the NEC-2 [Part I theory manual, §3](https://www.nec2.org/other/nec2prt1.pdf#page=21).

## Limits

Four selected frames span only three independent trajectories, with two frames from trajectory 10. Report individual-frame and trajectory-group descriptive summaries; do not produce a confidence bound or call 201 converged ground truth. This is validation data only, with no pilot or test rows opened. A small selected-frame result cannot replace the protocol's separate held-out action audit. Existing C1 artifacts remain immutable.
